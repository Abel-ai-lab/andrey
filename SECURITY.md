# Security

## Supported versions

Security fixes go into the latest release. Andrey is in its 0.x series, so upgrade to the newest
version to get them.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub: on the repository's
**Security** tab, choose **Report a vulnerability**. Include what you found, how to reproduce it, and
the version you used. We'll reply in the report and keep you informed until it is fixed.
