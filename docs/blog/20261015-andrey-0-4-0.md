# Pairwise direction

Does `x` cause `y`, or does `y` cause `x`? With only two variables, independence tests cannot tell:
both directions fit the data equally well. ANM and PNL instead use the shape of the relationship
to infer direction. We have supported both methods since 0.4.0, and from 0.16.0 their p-values stay
precise far below 1e-16. 0.16.0 also adds LOCI, experimental, for a pair whose noise grows or
shrinks with the cause.

We explain how two variables can reveal their direction, run ANM and PNL on two pairs, and report
the 0.4.0 benchmark results.

## Direction from two variables

PC and GES can orient an edge only through a third variable, such as a common effect. A pair has
no third variable, so `x -> y` and `y -> x` explain the data equally well. These methods leave the
edge undirected.

A model of the mechanism can break the tie. Suppose `y = f(x) + e`, where the noise `e` is
independent of `x`. Regress `y` on `x`, and the residual looks independent of `x`. Regress `x` on
`y`, and in general no residual is independent of `y`, unless `f` is linear and the noise is
Gaussian.

Each test fits both directions and checks whether the residual is independent of the proposed
cause. It uses HSIC, a kernel test that detects nonlinear dependence as well as correlation.
The direction whose residual looks independent is the causal one.

The methods fit different models:

- **ANM** (additive noise model) fits `y = f(x) + e` by Gaussian-process regression. The direction
  is generally identifiable when `f` is nonlinear or the noise is non-Gaussian.
- **PNL** (post-nonlinear model) fits `y = f2(f1(x) + e)`, where `f2` is invertible. This is an
  additive noise model observed through a distortion, such as a sensor that saturates. ANM is
  the case where `f2` changes nothing. PNL fits each transform as a sum of smooth basis functions.
- **LOCI** (location-scale noise model,
  [Immer et al., 2023](https://proceedings.mlr.press/v202/immer23a.html)) fits
  `y = f(x) + g(x) * n`, where the noise scale `g > 0` changes with the cause, so the spread of `y`
  can grow or shrink with `x`. ANM's additive noise does not allow that. In each direction, LOCI
  fits a Gaussian whose mean and variance are spline functions of the proposed cause, and tests the
  residual scaled by the fitted spread.

## Supported methods

A method becomes supported once we benchmark it against another package and check its results on
known data. ANM and PNL became supported in 0.4.0; PNL was experimental before.

| Method | Model | Returns |
|---|---|---|
| [ANM](../docs/api/andrey.anm.rst) | `y = f(x) + e` | A two-node DAG, both p-values, and both test statistics |
| [PNL](../docs/api/andrey.pnl.rst) | `y = f2(f1(x) + e)` | A two-node DAG, both p-values, and both test statistics |

Choose a method for your data:

- **ANM** when the effect is a smooth function of the cause plus independent noise. Its regression
  time grows with the cube of the number of rows, so it suits up to a few thousand rows.
- **PNL** when the effect may pass through a distortion or you have more rows. In the 0.4.0
  benchmarks, its median fit took under 2 s at 5,000 rows.
- **LOCI**, experimental, when the spread of the effect changes with the cause, such as a reading
  that grows noisier as it grows. Under its default criterion, its HSIC test's time and memory grow
  with the square of the number of rows.

LOCI, new in 0.16.0, is experimental: we are benchmarking it against its authors' code, and it
becomes supported once it passes. It decides one pair, as its paper defines no procedure for more
variables; for a graph, use CAM. Its likelihood assumes Gaussian noise, and the cause must range
without bounds, so a uniform cause is outside its model.

All three assume that no hidden common cause links the pair. When one is plausible, use the methods
in the [0.2.0 post](20261012-andrey-0-2-0.md).

## Reading the result

Each test returns a two-node DAG, and its `metadata` gives both directions' results, `forward` for
`x -> y` and `backward` for `y -> x`:

- `metadata["p_values"]`: the p-values of the two independence tests. A large p-value means the
  residual looks independent of the proposed cause, so that direction fits.
- `metadata["statistics"]`: the two HSIC statistics, each divided by its mean under independence.
  Smaller values mean weaker dependence.

By default, the edge points in the direction with the larger p-value. On a large sample, both
p-values can fall far below 1e-16. The tests compute each p-value through its logarithm, so it
stays precise, and compare the two logarithms, which keep their order even where both p-values fall
below about 1e-308 and print as 0. The statistics decide only between equal p-values, the smaller
one winning. This rule selects a direction even for unrelated variables.

With a significance level such as `alpha=0.05`, a direction fits when its p-value exceeds the
level. The test draws an edge only when exactly one direction fits.

LOCI reads the same way under its default, `criterion="independence"`: it tests each direction's
scaled residual, `(y - mu(x)) / sigma(x)`, against the proposed cause, and its p-values decide as
ANM's do. With `criterion="likelihood"`, it picks the direction whose model has the larger mean
log-likelihood, which `metadata["log_likelihoods"]` gives under both criteria, and draws no edge on
a tie.

- **Saturating**: a sensor reads `y = tanh(x + 0.5 * e)`. The noise passes through the

On the additive pair, ANM and PNL both select the true direction, `x -> y`, and reject `y -> x`.

On the saturating pair, the distortion breaks ANM, and PNL models it:

- ANM rejects both directions. Both p-values are near zero because the saturation is not additive
  noise. Its default rule still selects a direction, here the reversed one, `y -> x`. With

- PNL models the saturation as its outer transform. Its p-value for `x -> y` is large.
  Its p-value for `y -> x` is near zero, so it selects the true direction.

## Benchmark results

For 0.4.0, we compared both methods with causal-learn, a Python package that implements them, on
simulated cause-effect pairs. We tested ANM on additive-noise pairs and PNL on post-nonlinear pairs.
The precise p-values of 0.16.0 changed no direction on 970 pairs drawn as these benchmarks draw
theirs, from 200 to 16,000 rows.

| Method | Compared with | Andrey's speedup | Direction |
|---|---|---|---|
| ANM | causal-learn | about 2x | the same as causal-learn's on every pair |
| PNL | causal-learn | up to 1,470x | true on more pairs than causal-learn's |

The [0.4.0 release card](../docs/benchmarks/0.4.0.md) reports every measurement, including the
sizes, machine, and settings.

Our ANM implementation fits the same Gaussian process and uses the same independence test as
causal-learn, so in the 0.4.0 benchmarks both returned the same graph on every pair.

The PNL implementations differ more in how they fit and test each direction. In the 0.4.0
benchmarks, ours selected the true direction on 94% of pairs; causal-learn's selected it on 45%.

test selects a direction on every pair, right or wrong. Check both p-values before you trust it.

## Other highlights

- **Precise p-values.** From 0.16.0, a p-value below about 1e-16 no longer rounds to 0. Where both
  p-values used to read 0 and the smaller statistic decided, the larger p-value now decides. Every
  method that tests with HSIC computes its p-values this way, among them RCD, BottomUpParceLiNGAM,
  GIN, and the KCI test without conditions.
- **ANM in any units.** ANM standardizes each column first, so its answer does not depend on either
  variable's units.
